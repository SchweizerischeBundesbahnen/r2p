== Overview

R2P is a prototype demonstrating RU - RU - partner communication. To keep things leightweight and portable
the prototype uses Java and H2 (no need for a dedicated database server).

== Quick Start

=== Execute the prototype
[source,bash]
----
mvnw spring-boot:run
----

Visit: http://localhost:8080/

Note: in order to access secured endpoints, you need to be a member of the AD-group xy.

== Domain Model

Each train, variant and version is represented by following model. A train is releated to partners. It has a main variant which is the current state. A change can be submitted by creating a new variant.
Every change of the variant creates a new version. The changes of the variant can be applied to the main variant. Changes can be commented. The payload contains all data. Identifiers are 'trainId' and 'version'.

[plantuml, uml-diagramm, png]
----
@startuml

class TrainRow {
  ~ trainId: UUID
  ~ trainNumber: String
  ~ operationalDay: LocalDate
  ~ variant: String
  ~ comment: String
  ~ payload: Train
  ~ partners: List<PartnerType>
  ~ timestamp: OffsetDateTime
  ~ version: UUID
}

@enduml
----

== REST Endpoints

See also: link:../src/main/resources/openapi/r2p-spec.yaml[r2p-spec.yaml]

=== Train

* GET /trains - list all trains which are availble for the partner, the response shows all variants with their latest version
* POST /trains - creates a new train with the given payload
* POST /trains/{trainId}/share - shares the train with another partner
* GET /trains/{trainId} - gets the the train by the passed trainId, the response shows all variants with their latest version
* PUT /trains/{trainId} - creates a new version of train with the given payload

=== Variant

* GET /trains/{trainId}/variants/{variant} - gets the variant by the passed variant name
* GET /trains/{trainId}/{version} - gets the specific version of the train
* PUT /trains/{trainId}/variants/{variant} - creates a new version of the variant with the given payload
* DELETE /trains/{trainId}/variants/{variant} - deletes the variant

=== Changes
* GET /trains/{trainId}/changes - gets all changes for the train with the passed trainId
* GET /trains/changes - gets all changes for all trains available for the partner
