== Overview

R2P is a prototype demonstrating RU - RU - partner communication. To keep things leightweight and portable
the prototype uses Java and H2 (no need for a dedicated database server).

== Quick Start

=== Execute the prototype
[source,bash]
----
mvnw spring-boot:run
----

Visit: http://localhost:8080/

Note: in order to access secured endpoints, you need to be a member of the AD-group xy.
