= Domain Model

The R2P system manages trains with multiple branches and versions. The core domain model consists of three main entities:

== TrainVersion

Represents a specific version of a train at a point in time. Each version contains:

* `version` (UUID) - Unique identifier for this version
* `trainId` (UUID) - Identifier linking all versions of the same train
* `trainNumber` (String) - The train number (e.g., "IC 1234")
* `operationalDay` (LocalDate) - The operational day for this train
* `branchId` (UUID) - Reference to the branch this version belongs to
* `comment` (String) - Description of changes in this version
* `timestamp` (OffsetDateTime) - When this version was created
* `payload` (Train) - The full train data according to the Train schema
* `head` (boolean) - Whether this is the latest version of its branch

== Branch

Represents a branch of a train (similar to Git branches). Each branch contains:

* `branchId` (UUID) - Unique identifier for this branch
* `trainId` (UUID) - Reference to the train this branch belongs to
* `name` (String) - Branch name (e.g., "main", "feature-branch")
* `owner` (String) - Partner who owns/created this branch
* `state` (BranchState) - Current state: `OPEN`, `MERGED`, or `DELETED`

The main branch is always named "main" and represents the current agreed-upon state of the train.

== TrainVersionEnriched

A read model that combines a TrainVersion with its Branch information and list of partners who have access to the train:

* `trainVersion` (TrainVersion) - The version data
* `branch` (Branch) - The associated branch
* `partners` (List<String>) - List of partner names with access

== Changelog

Tracks all changes made to trains:

* `id` (UUID) - Unique identifier for this change log entry
* `action` (Action) - Type of action: `CREATED`, `UPDATED`, `MERGED`, `DELETED`, `SHARED`, `UNSHARED`
* `partner` (String) - Partner who performed the action
* `affectedPartner` (String) - Partner affected (for share/unshare operations)
* `trainId` (UUID) - Train involved in the action
* `branchId` (UUID) - Branch involved (if applicable)
* `branchName` (String) - Name of the branch
* `version` (UUID) - Version created/affected (if applicable)
* `timestamp` (OffsetDateTime) - When the action occurred
* `comment` (String) - User-provided comment

== Train Payload Schema

The actual payload (`TrainVersion.payload`) corresponds to the schema defined in `src/main/resources/openapi/schemas/train.yaml`, which is the same schema used in the REST endpoints. This schema contains comprehensive train information including journey details, rolling stock, staff, requirements, and capabilities.
